# API reference

The interactive documentation is generated by FastAPI:

* Swagger UI — <http://127.0.0.1:8000/docs>
* ReDoc — <http://127.0.0.1:8000/redoc>
* OpenAPI JSON — <http://127.0.0.1:8000/openapi.json>

## Conventions

* Every payload is JSON. Errors use FastAPI's format: `{"detail": "..."}`.
* `GET /health` and `GET /ready` never require authentication.
* When `RQM_API_KEY` is set, every other endpoint requires the header
  `X-API-Key: <value>`; a wrong or missing key returns **401**.
* A per-IP rate limit is applied (`RQM_RATE_LIMIT_PER_MINUTE`, default 600);
  exceeding it returns **429**.
* Query parameters that filter a list are optional and combine with AND.
* Destructive operations (`DELETE`) remove the object and everything that
  belongs to it, and refuse to break the audit trail (a dataset referenced by a
  run returns **409**).

## Examples

### Start a run and wait for it

```bash
curl -X POST http://127.0.0.1:8000/api/runs \
  -H 'Content-Type: application/json' \
  -d '{"app_id": 2, "dataset_id": 1, "mode": "end_to_end", "wait": true}'
```

```json
{
  "id": 7,
  "status": "completed",
  "metrics": {
    "metrics": {
      "recall_at_5": { "value": 1.0, "n": 35, "kind": "deterministic", "std": 0.0 },
      "token_f1":   { "value": 0.6777, "n": 28, "kind": "reference_based", "std": 0.21 }
    }
  }
}
```

### Evaluate a release gate

```bash
curl -X POST http://127.0.0.1:8000/api/gate-policies/1/evaluate \
  -H 'Content-Type: application/json' \
  -d '{"candidate_run_id": 4}'
```

```json
{
  "verdict": "FAIL",
  "summary": "FAIL: 4/6 checks passed, 2 failed",
  "checks": [
    {
      "metric": "recall_at_5", "type": "min", "severity": "hard",
      "observed": 0.4, "threshold": 0.8, "n": 35, "status": "FAIL",
      "evidence": "Candidate 0.4000 < required 0.8 (n=35)."
    }
  ]
}
```

### Compare two versions

```bash
curl "http://127.0.0.1:8000/api/compare?a=2&b=4"
```

The response contains the per-metric table, the per-question deltas, whether
the two runs are *comparable* (same dataset checksum) and the per-question
top-5 document lists so you can see exactly what changed in retrieval.

### Import a benchmark

```bash
curl -X POST http://127.0.0.1:8000/api/datasets/1/import \
  -F 'file=@examples/dataset.jsonl'
```

```json
{ "imported": 2, "skipped_duplicates": 0, "received": 2 }
```

### Export a CI summary

```bash
curl "http://127.0.0.1:8000/api/runs/4/export?format=ci&gate_policy=1"
```

The `ci` format is a compact, machine-readable object with the verdict, the
checks and the metrics — designed to be stored as a CI artifact.
